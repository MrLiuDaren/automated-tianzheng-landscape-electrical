# 自动化天正景观电气图

一个面向 Codex 的开放式 Skill，用于室外景观配电施工图的规划、天正落图、校核与交付。它把总图、运营需求、建筑预留电源、现场空间约束和参考图纸组织成可追溯的数据与图面，而不是只生成一张“看起来像电气图”的 CAD 文件。

## 能做什么

- 计算景观灯具、市集摊位、舞台、快闪和预留泛光的用电负荷。
- 划分总箱、末端服务箱、回路、电源桩、接驳点和手孔井。
- 在 T20 天正建筑中布置设备、绘制线路、增加中文图例与引出标注。
- 优先结合绿化布置设备和走线，并核对铺装穿越、检修条件和空间冲突。
- 回读 DWG 实体，输出点位、负荷、回路、箱体及覆盖关系。
- 按需生成 JPG、PDF、Excel、系统图或分页说明。

## 环境要求

- Windows 与 Codex。
- T20 天正建筑，并已提供可用的天正 MCP。
- Python 3，用于运行登记表校验脚本。

## 安装

```powershell
$skillDir = Join-Path $env:USERPROFILE '.codex\skills\automated-tianzheng-landscape-electrical'
git clone https://github.com/MrLiuDaren/automated-tianzheng-landscape-electrical.git $skillDir
```

如果本地已经安装，更新到最新版本：

```powershell
git -C $skillDir pull --ff-only
```

## 基本用法

在 Codex 中直接引用 Skill：

```text
使用 $automated-tianzheng-landscape-electrical 完成本项目室外景观配电。
先读取我提供的总图、运营提资、建筑电源条件和参考电气图，
建立负荷、点位、回路、箱体和手孔井关系；核对无误后再在当前天正图中落图并回读验收。
```

只做方案时，可以明确要求先不给 DWG 落图：

```text
使用 $automated-tianzheng-landscape-electrical 先完成负荷计算、回路划分、
配电箱与取电点方案、走线策略和待确认项，不修改当前 DWG。
```

## 推荐提供的最小资料

| 资料 | 用途 |
|---|---|
| 最新目标 DWG 与参考图 | 确认底图、空间、图例、图层和绘图样式 |
| 运营或景观提资 | 明确灯具、摊位、舞台、快闪、泛光和取水需求 |
| 建筑预留电源资料 | 确认电压、相数、容量、接入位置和专业界面 |
| 图纸版本与交付要求 | 确认目标文件、比例、编号方式及 JPG/PDF/Excel 需求 |

项目专属的容量、编号、坐标和数量应由当前项目状态文件与登记表承载，不写入 Skill 的通用规则。

## 最后交付什么

Skill 的最终成果不是一个孤立的 DWG，而是可供施工继续深化和复核的一套交付内容。涉及出图和修改 DWG 时，核心交付至少包括：

| 交付物 | 应包含的内容 |
|---|---|
| 可编辑 DWG | 最新配电点位、线路、箱体、手孔井、中文标注、图例和必要说明 |
| 回路负荷登记表 | 每个回路的连接负荷、需要系数、设计负荷、计算电流、保护与上游关系 |
| 点位登记表 | 设备、箱体、井、接驳点、摊位和灯具的唯一编号、位置及服务关系 |
| 图面样式登记表 | 图层、颜色、线型、线宽、块、字高和标注做法 |
| 校核记录 | 回读结果、点位数量、回路汇总、总图与局部图检查结果 |
| 交付说明 | 文件绝对路径、已完成内容、暂定参数、未决事项和下一版续接文件 |

以下内容按本次任务增加：

- 修改前 DWG 备份。
- 配电系统图、索引图或设计说明。
- JPG 或 PDF 分页图。
- Excel 版点位、负荷、材料或箱体覆盖清单。
- 材料表、电缆表、灯具表和手孔井统计。

只有负荷与回路关系自洽、图上对象与登记表双向对应、关键写入已回读、交付文件可重新打开，并且未决事项已明确记录，才可将本轮称为完成。

详细验收口径见 [校核与交付](references/qa-delivery.md)。

## 工作边界

这个 Skill 负责景观配电规划、天正落图和图面校核。建筑内部配电、给排水水力计算、市政供电报装和法定审图仍需相应专业资料或专业人员确认。交付结果也不等于“已通过审图”。
