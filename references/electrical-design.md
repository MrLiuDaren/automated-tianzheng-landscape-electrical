# 室外景观配电设计

## 1. 资料闭环

电气方案开始前，把以下信息逐项落到项目状态或登记表：

- 建筑可提供的电源位置、容量、相数、电压、保护配置和接入界面。
- 景观总图的最新版本、坐标基准、绿化范围、铺装范围、建筑和构筑物边界。
- 庭院灯、草坪灯、射树灯及预留照明的型号、功率、数量和控制要求。
- 舞台、市集、外摆摊位、快闪或品牌区域的规模、位置、运营设备和使用时段。
- 泛光照明、水景、充电或其他后续负荷的预留要求。
- 箱体、手孔井、电缆沟、套管、埋深和接地等土建配合条件。
- 当地执行标准、设计说明和审图要求。

设备规格缺失时，可以先采用项目标准或明确标注的估算值，但必须注明假设、依据和复核节点。

## 2. 编号体系

编号应表达对象类型，并保持跨图纸、表格和标注一致。可采用以下语义前缀，具体规则由项目统一确定：

| 前缀 | 对象 |
|---|---|
| `BI` | 建筑向景观提供的电源接口 |
| `AL` | 配电箱或总箱 |
| `W` | 市集或动力主干回路 |
| `N` | 景观配电分支回路 |
| `SC` | 末端服务箱 |
| `MJ` | 摊位电源点或摊位编号 |
| `ST` | 舞台接驳点 |
| `QF` | 快闪或品牌接驳点 |
| `FB` | 泛光照明预留点 |
| `J` | 手孔井或检修井 |
| `CY` | 庭院灯 |
| `CL` | 草坪灯 |
| `TR` | 乔木射树灯 |

规则：

- 类别前缀与数字之间使用固定分隔符。
- 数字位数固定，保证排序和打印一致。
- 一个编号只对应一个物理对象。
- 箱内回路编号与图上线号一致；线号不得被灯具编号复用。
- 点位移动但功能不变时可保留编号，并用修订记录说明；原件替换则新建编号。

## 3. 负荷计算

### 3.1 单类负荷

```text
连接功率 = 数量 × 单台额定功率
设计功率 = 连接功率 × 需要系数
```

灯具的驱动损耗、控制器和预留比例应按设备资料或项目规则处理，不能默认忽略。

### 3.2 回路和总箱

先按功能和同时使用关系分组，再在组内和组间采用合适的同时系数。不要把所有末端额定功率直接相加后当作设计负荷，也不要用“上游箱标称容量”代替实际计算。

至少输出以下字段：

- 回路编号。
- 服务对象和覆盖数量。
- 单台功率。
- 连接负荷。
- 需要系数。
- 设计负荷。
- 功率因数。
- 计算电流。
- 保护器件。
- 电缆规格和长度。
- 电压降估算。
- 上游接口和备用容量。

### 3.3 电流估算

三相平衡负荷：

```text
I = P / (√3 × U × cosφ)
```

单相负荷：

```text
I = P / (U × cosφ)
```

P 应采用与计算场景一致的功率单位；电压、功率因数和敷设修正条件必须来自实际设计条件。

### 3.4 上游容量判断

把建筑电源条件与景观需求比较时，要同时核对：

- 标称单位是 kW 还是 kVA。
- 三相是否平衡，是否存在显著单相负荷。
- 需要系数和不同区域的同时使用关系。
- 灯具驱动功率和启动特性。
- 舞台、摊位、快闪是否在运营高峰同时用电。
- 保护器件、中性线和接地系统是否匹配。
- 电压降和未来预留。

因此，多个下游箱各有标称容量，不能直接推出上游接口“够用”或“不够用”。正式结论必须附计算表。

## 4. 配电层次

典型层次为：

```text
建筑预留接口
  → 景观总配电箱
  → 区域或功能主干
  → 末端服务箱 / 驱动电源 / 控制箱
  → 灯具、电源桩、接驳点
```

设计时应确认每一级的保护选择性和检修隔离条件。舞台、泛光、市集和普通照明通常需要独立控制或独立隔离，避免单一区域检修使全园失电。

## 5. 市集、摊位与运营负荷

连续摊位不应被一个普通插排串接。推荐采用：

- 总箱按区域划分主干。
- 每个服务箱覆盖一个可管理的小组。
- 每个摊位设置可识别、防雨、可检修的电源点。
- 服务箱到各电源点的回路关系、保护和相序明确。

末端箱的若干插座规格描述的是出线能力，不代表可以同时独立控制任意数量的摊位。若服务箱覆盖的摊位数量多于可独立分配的出线数，必须明确：

- 哪些摊位共用同一保护区段。
- 每个插座或电源桩的额定电流。
- 同时使用上限。
- 单点故障对同组摊位的影响。
- 是否允许运营人员更换大功率设备。

图上应表达服务箱到摊位的覆盖关系，必要时用服务范围示意图和末端箱系统图共同说明。

## 6. 灯具与驱动

- 先核对灯具额定电压。不能因为图例相同就默认所有灯具可直接接入同一电压等级。
- 低压或安全特低电压系统需要按所选系统核对隔离、驱动、回路长度和电压降。
- 常规 220V LED 灯具是否需要变压器，应由灯具类型、驱动形式和项目标准决定，不能一概而论。
- 室外灯具和接线腔应满足项目要求的防护等级。
- 控制方式、定时、光控和接触器/驱动布置应在系统图中表达。
- 回路计算应包含驱动损耗、控制设备和预留。

## 7. 点位布置

### 7.1 灯具

- 庭院灯按步行动线、照度、间距、遮挡和眩光控制布置。
- 草坪灯只放置在有明确草坪、绿篱或可安装土层的区域，不能落入铺装。
- 射树灯与真实乔木位置对应；同一棵树的照明方式和数量应在登记表中体现。
- 灯具与树池、园路、建筑出入口、摄像头和景观小品协调。

### 7.2 取电设施

- 优先放在灌木、绿篱或非通行硬质边界附近，并保留检修空间。
- 不放入座凳内部、装饰面层内部或需要拆卸园林构件才能检修的位置。
- 若只能落铺装，采用专用井座或防护设施，表面齐平、无绊倒风险，并说明防水、排水和检修方式。
- 设备不能正面在主要观景面裸露；隐蔽不能以牺牲操作和维护为代价。

### 7.3 舞台、快闪和泛光

- 根据活动设备、面积和运营强度计算或明确估算负荷。
- 接驳点靠近演出或品牌区域，但避开人群踏踩、舞美基础和水景喷溅区。
- 演出、快闪、泛光预留点分别编号，不能共用一个无标识插座。
- 泛光方案尚未确定时，预留位置、容量和控制界面应可继续深化。

## 8. 走线

优先顺序：

1. 绿化带或专用电缆沟。
2. 建筑物边缘、园路边缘的可检修浅沟或套管。
3. 硬质铺装内套管。
4. 不具备条件的位置，提出井、沟或结构配合方案。

走线设计至少明确：

- 起止点、方向和从左到右/从箱到末端的顺序。
- 敷设方式与埋深。
- 套管材质、规格和穿越位置。
- 砂垫层、保护盖板、警示带或标识要求。
- 过路、转弯、分支、长距离和检修位置的井。
- 与给排水、燃气、通信、热力和构筑物基础的净距。
- 防机械损伤、排水和接地措施。

图上线段应连续，尽量避免多处交叉和反复回头。设备摆放以后，线路应从设备实际接入点出发，而不是从围合框中心随意连出。

## 9. 手孔井

手孔井不是每个设备旁机械复制一个，也不是只在图上为了好看放置。应结合：

- 主干分支和电缆接头。
- 管路转弯。
- 穿越铺装、道路或结构的位置。
- 长直线段的检修需求。
- 箱体、电源桩和接驳点的接线条件。
- 排水、盖板荷载和景观铺装协调。

井位与编号必须进入点位登记表，并注明服务于哪条回路或哪个对象。若井内需要接头，应说明防水接线和检修要求。

## 10. 保护、接地与安全配合

以下内容必须按照现行国家/地方标准、项目设计说明和设备资料核查，本 Skill 不替代正式计算：

- 过载、短路和剩余电流保护。
- 防雷、浪涌保护和接地。
- 等电位联结。
- 室外插座和箱体的防护等级。
- 检修隔离与上锁管理。
- 水下、喷泉、涉水区域的特殊安全要求。
- 三相负荷平衡和中性线截面。
- 保护导体的连续性。

涉及新增建筑接驳、扩容或改变建筑预留条件时，必须把建筑专业输入和界面责任标清楚。

## 11. 取水及综合管线协调

取水点与取电点均应以“可检修、避通行、结合绿化、便于运营”为原则。综合管线出现冲突时：

- 不在图上用交叉线表示“已经解决”。
- 记录冲突对象、净距和待协调方。
- 需要改线时同时检查电、水、排水的埋深和坡度约束。
- 取水设备附近应有排水和防回流等专业措施，由给排水专业确认。

## 12. 方案完成条件

- 所有运营区域有明确取电接口。
- 所有灯具和电源点有唯一编号、回路和上游。
- 所有箱体和井有位置、容量、服务范围和检修条件。
- 计算表支持上游容量和保护选择。
- 走线可从图中完整追踪，并说明穿越铺装措施。
- 未决事项明确标注，没有被隐藏成“已解决”。
