# 工作流与安全

## 1. 输入优先级

出现冲突时，按可追溯性和时效性判断，而不是按文件大小或生成时间猜测：

1. 当前用户明确变更和已确认版本。
2. 最新建筑、景观总图及专业提资。
3. 本项目执行的标准、设计说明、负荷表和审图意见。
4. 运营需求和设备规格。
5. 历史图纸、聊天记录和自动生成结果。

每组关键输入都应在项目状态中记录来源、日期、版本和用途。无法确认来源的数据先标为“暂定”，不得用确定口吻写进正式标注或计算书。

## 2. 开始写图的基本条件

写入 DWG 前必须满足以下条件：

- 已识别目标项目或图纸的唯一标识。
- 已确认目标 DWG 的绝对路径。
- 已确认当前打开的是该文件，而不是同名旧版或恢复副本。
- 已读取已有实体、图层、块和视口等基本信息。
- 已确认没有命令行正在执行，也没有其他软件或脚本同时占用该图。
- 已保存或建立可恢复快照。
- 已明确本轮要新增、修改或删除的对象及其范围。

任何一项不清楚时，可继续只读查询。若写入目标本身无法确定，不要猜一个文件继续画。

## 3. T20 天正连接检查

使用本机 T20 天正环境。典型检查顺序：

1. `tz_status`：确认天正 MCP、AutoCAD 和天正插件状态。
2. `tz_ping`：确认实时命令能返回结果。
3. 绑定或打开准确的目标图。
4. `tz_drawing_info`：读取当前文件、空间和单位。
5. `tz_entity_stats`：抽样读取图层、块和实体分布。

如果用户已经打开工作图，优先接续当前活动文档，不要无必要地重新 `tz_open`。若必须打开文件，必须使用准确绝对路径，并确认不会创建新的空白图或切换错窗口。

写入前还要确认：

- 当前空间正确（模型空间或目标布局）。
- 当前图层不是不可见、冻结或锁定的目标层。
- `OSNAP`、动态输入和选择集状态不会意外改变坐标。
- 命令行状态为空，没有等待输入的半执行命令。
- 目标区域没有被外部参照或裁剪视口遮挡。

## 4. 备份与命名

重要修改前建立带时间戳的副本，命名至少包含：

```text
<图名>_<阶段或版本>_<修改内容>_<YYYYMMDD-HHMM>.dwg
```

备份应与工作图位于可识别的同一项目目录，或在项目状态中记录完整路径。不要用“final”“new”“修”等无法排序的名称作为唯一版本标识。

交付前区分：

- 原始底图：只读保留。
- 工作图：本轮实时编辑文件。
- 修改前快照：可回滚备份。
- 交付图：完成回读、看图和必要导出后的版本。

## 5. 禁止并发写入

同一个 DWG 只允许一个写入者。以下工具不得同时对同一文件执行写操作：

- 天正 MCP 的实时命令或 AutoLISP。
- AutoCAD COM。
- 离线 DWG 写入库。
- 批量脚本、格式转换器或第三方 CAD 插件。

只读解析可以作为独立核对，但不能与实时写入并行保存同一文件。若发现文件锁定、保存被拒绝或版本突然变化，立即停止写入，转为只读诊断。

## 6. 安全写入顺序

推荐把一批修改拆成可验证的小组：

1. 建所需图层、块和样式，暂不移动原对象。
2. 布置设备、箱、井和接驳点。
3. 绘制电缆、套管或保护路径。
4. 加入编号和中文引线标注。
5. 回读实体和关键属性。
6. 截图检查总图与局部。
7. 保存，并再次确认当前文件和保存时间。

每次分组修改后记录新增或改变的对象句柄、数量和图层。不要一次执行数百个对象后再找错误。

## 7. 命令成功不等于图纸正确

以下情况都可能出现“命令返回成功”：

- 对象画在零层或当前错误图层。
- 块被匿名化、缩放错误或属性丢失。
- 文字编码正常但字体缺失，显示问号。
- 线段在视觉上相连，实际没有公共端点。
- 标注避开了一个视口，却在打印样式下遮挡。
- 实体被重复插入，图面上只看见一个。
- 临时修改没有真正保存到目标图。

因此每个阶段至少执行一种独立验证：

- 重新查询实体和属性。
- 比较修改前后的实体统计。
- 检查关键对象句柄。
- 放大截图检查端点、文字和块。
- 打开交付副本做一次只读复核。

## 8. 失败与恢复

连接失败时先区分软件未启动、插件未加载、命令忙、活动文件不匹配和 MCP 服务中断。优先检查状态和当前窗口，不要通过反复重启或批量重试掩盖问题。

保存失败或图纸状态异常时：

- 立即停止新增写入。
- 保留当前文件和已有备份。
- 记录失败命令、时间和可观察状态。
- 用只读方式检查文件是否存在、最后修改时间和锁定情况。
- 向用户报告具体阻塞点和已完成的部分。

可以继续做负荷表、点位表、文字说明和独立备份分析，但不要声称工作图已更新。

## 9. 变更可追溯

每轮修改至少记录：

- 输入依据和用户变更。
- 目标文件和备份路径。
- 新增、修改、删除的点位及编号。
- 回路、箱体和负荷变化。
- 走线变化及穿越硬质铺装的措施。
- 回读结果和看图结果。
- 尚未解决的问题。
- 下一版应从哪个文件继续。
